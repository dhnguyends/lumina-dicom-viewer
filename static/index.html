 BIENVENUE DANS LUMINA

Un regard plus simple.

Sélectionnez une coupe pour afficher ses détails. Double-cliquez sur une image ou appuyez sur Espace pour l’agrandir.

Le curseur « Aperçus » redimensionne toutes les vignettes. Dans la visionneuse, utilisez ← et → pour parcourir la série, et + / − pour zoomer.

« Nouvelle fenêtre » ouvre une visionneuse indépendante. Importez des DICOM CT monochromes à une image par fichier (256 Mo maximum par lot). Les séries sont regroupées par acquisition et géométrie.

Consulter le guide utilisateur illustré

Traitement local. Aucun service externe. Les imports sont conservés dans le dossier data/imports. Les favoris et la taille des aperçus sont mémorisés dans ce navigateur. Les images restent des données médicales ; cette application n’effectue pas d’anonymisation.
